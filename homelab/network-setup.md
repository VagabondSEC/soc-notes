# Network Setup

## Le réseau du lab

Un réseau privé isolé (10.0.0.0/24) pour les VMs
Le host accède au lab via une interface dédiée
La segmentation reproduit un vrai environnement d'entreprise

## Les services du lab

Active Directory : le cœur d'un environnement Windows
Un DNS interne pour les noms de machines
Le partage de fichiers SMB pour les mouvements latéraux
